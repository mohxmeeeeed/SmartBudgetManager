# SmartBudget Manager

## Overview
**SmartBudget Manager** (`SmartBudget_Manager.xlsx`) is a simple Excel workbook designed to help users manage their personal finances easily. It allows you to:
- Record monthly income and expenses.
- Categorize expenses (Food, Transport, Rent, Health, Education, etc.).
- Calculate the monthly balance automatically.
- Display a visual chart of expenses by category.
- Receive an automatic warning when the budget limit is exceeded.

## Workbook Structure
The workbook contains three main worksheets:
- **Dashboard**: Displays the monthly balance, total income, total expenses, and expense charts.
- **Transactions**: Where you enter your daily income and expenses.
- **Categories**: Contains the predefined expense categories.

## Requirements
- Microsoft Excel 2016, 2019, 2021, Microsoft 365, or any equivalent compatible spreadsheet software.

## How to Get Started
1. Download and open `SmartBudget_Manager.xlsx`.
2. Go to the **Transactions** worksheet to add your income and expenses, selecting the appropriate category for each entry.
3. Open the **Dashboard** worksheet to view your updated monthly balance, charts, and budget warnings.
